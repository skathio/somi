### Supplementary: the front door's own context (outside the sealed rule)

The sealed scenarios have no front-door case, so this is measured with the same L0 tool and two
scenario files, [`6e4701a-front-door-base.json`](./6e4701a-front-door-base.json) (run on the baseline) and
[`6e4701a-front-door-cand.json`](./6e4701a-front-door-cand.json) (run on the candidate tree with the
dispatcher wording that followed the live runs). Each lists what the `somi` agent's own context holds for
one request: on the baseline the agent, the skills it loads and every command procedure it runs itself;
on the candidate the agent and the skills it loads, since procedures now run in `somi-flow`.

| Request | Baseline bytes | Candidate bytes | Change |
|---|---|---|---|
| `@somi /plan …` | 53348 | 25035 | -53.1% |
| `@somi <free text routed to /plan>` | 63982 | 36259 | -43.3% |
| `@somi /ship-loop …`, a full run | 114746 | 25035 | -78.2% |

This is not a verdict under the rule and not a per-request total: the runner and the specialists hold
the procedures in their own contexts. What it measures is the context the dispatcher has to keep its
instructions in view against, which is the failure this release addresses.

## Limits

- Per release, not per commit: the result covers every change in the release together.
- The verdict is for the recorded model tier only; context-size effects transfer in direction, sizing and
  other behaviour effects do not.
- L0 is exact bytes injected, not tokens billed. L1 is one host fingerprint. Live L2 resolves only large
  changes (about 50% or more); smaller changes read inconclusive by design.
- Quality is a coarse non-inferiority flag only; no quality win or loss is declared.
- L2 was not run: it needs a paid recording approved for this release. L2 drives Claude Code only, so it
  could show the cost of the extra skill loads on typed commands; it cannot see the Copilot front door.
- The release's main claim, that the front door dispatches instead of doing the work, is behavioural and
  Copilot-only. No layer of this instrument measures it; the evidence for it is the live Copilot CLI runs
  described in the 4.1.0 CHANGELOG entry.
