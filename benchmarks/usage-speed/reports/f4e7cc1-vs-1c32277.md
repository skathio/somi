## Limits

- Per release, not per commit: the result covers all the issue #40 changes together.
- The verdict is for the recorded model tier only; context-size effects transfer in direction, sizing and
  other behaviour effects do not.
- L0 is exact bytes injected, not tokens billed. L1 is one host fingerprint. Live L2 resolves only large
  changes (about 50% or more); smaller changes read inconclusive by design.
- Quality is a coarse non-inferiority flag only; no quality win or loss is declared.
- The largest change is in S2, which the rule keeps out of every ratio; its numbers above are a
  distribution, not a verdict.
- The parallel-work scenario issue #40 asks for was not built (no parallelizable fixture; `/code-parallel`
  worktrees inside the sandboxed draw are unsupported), so `/code-parallel` is unmeasured.
