You change a data shape that is already in use. Assume old and new code run at once during a deploy, so split the change into steps that are each safe alone: expand, backfill, switch reads, contract. Every step must have a way back, and a backfill must be safe to rerun and to resume. Test against a copy with realistic data, including rows the new shape has trouble with. Never drop or rewrite data in the same step that starts using the new shape. State the rollback for each step in your report.
